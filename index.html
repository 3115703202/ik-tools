01 / CORE

无线调试授权优先，安装不再弹系统页

只要 Shizuku 无线调试已连接并授权，安装或更新 APK 会优先走 shell 身份：pm install -r -d -S 直接把文件流进 shell，不依赖「未知来源」、不弹系统安装器。内置特权核心、IK 自身更新、安装器、备份恢复、下载中心统一走这条链路；没授权才自动退回系统安装页。

06 / FAQ
Shizuku 显示「已连接 · 待授权」怎么办？

先在 Shizuku 应用管理里把 IK 的开关关掉再打开，回 IK 点「立即授权」。5.0.21 起已修正 attachApplication 事务码（18 → 17）；如果仍是待授权，把 Shizuku 停止再启动一次，服务端版本要和 App 一致。

为什么安装没弹系统页？

因为无线调试已授权，安装走了 Shizuku shell 的 pm install -S。这是预期行为。没授权或执行失败时才会回退系统安装器。

隐藏 IK 后怎么回来？

通知栏常驻的「IK工具箱图标已隐藏」点一下，或拨号盘输入 *#*#9527#*#*。5.0.24 会先广播删旧快捷方式；如果 ROM 不吃这个广播、旧图标还在，点它会进应用详情，长按删掉那一个即可。

会不会上传文件或对话？

本机 AI、LENS 本机视觉、局域网互传都在设备内完成。只有你主动使用网页版、网盘解析或在线下载时才联网。

支持哪些机型？

Android 7.0+，arm64。Android 11+ 的无线调试、Shizuku 授权流程按各家 ROM 做了兜底；老旧电视浏览器请用完整包里的轻量页面。
